# PreLegal

پلتفرمی برای تهیه‌ی پیش‌نویس قراردادهای حقوقی رایج (**A platform for drafting common legal agreements**).

## دیتاست چیست؟

دیتاست، مجموعه‌ای از **قالب‌های (template) آماده‌ی قراردادهای حقوقی** به زبان انگلیسی و در قالب فایل‌های Markdown است. این قالب‌ها استاندارد و عمومی‌اند و می‌توان از آن‌ها برای ساختن پیش‌نویس قرارداد (مثلاً با پر کردن فیلدهای صفحه‌ی اول قرارداد) استفاده کرد.

## محل دیتاست

همه‌ی فایل‌ها داخل پوشه‌ی [`templates/`](templates/) قرار دارند:

| فایل | توضیح |
|------|-------|
| `Mutual-NDA.md` | شرایط استاندارد قرارداد عدم افشای متقابل (Mutual NDA) |
| `Mutual-NDA-coverpage.md` | صفحه‌ی اول (Cover Page) قرارداد Mutual NDA؛ فیلدهایی که کاربر باید پر کند |
| `AI-Addendum.md` | الحاقیه‌ی هوش مصنوعی |
| `Business-Associate-Agreement.md` | قرارداد شریک تجاری (BAA) |
| `Cloud-Service-Agreement.md` | قرارداد خدمات ابری |
| `Data-Processing-Agreement.md` | قرارداد پردازش داده (DPA) |
| `Design-Partner-Agreement.md` | قرارداد شریک طراحی |
| `Partnership-Agreement.md` | قرارداد مشارکت |
| `Pilot-Agreement.md` | قرارداد پایلوت |
| `Professional-Services-Agreement.md` | قرارداد خدمات حرفه‌ای |
| `Service-Level-Agreement.md` | قرارداد سطح خدمات (SLA) |
| `Software-License-Agreement.md` | قرارداد مجوز نرم‌افزار |
| `LICENSE.txt` | متن مجوز استفاده از قالب‌ها (CC BY 4.0) |

## منبع

قالب‌ها از سازمان **Common Paper** گرفته شده‌اند که قراردادهای استاندارد را به‌صورت متن‌باز منتشر می‌کند:

- سازمان در گیت‌هاب: <https://github.com/CommonPaper>
- مخزن Mutual NDA: <https://github.com/CommonPaper/Mutual-NDA>
- وب‌سایت: <https://commonpaper.com/>

## مجوز

قالب‌ها تحت مجوز **Creative Commons Attribution 4.0 International (CC BY 4.0)** منتشر شده‌اند. یعنی می‌توانید آن‌ها را آزادانه کپی، ویرایش و حتی تجاری استفاده کنید، به شرطی که:

- به **Common Paper** به‌عنوان منبع اشاره کنید،
- لینک مجوز را بدهید،
- اگر تغییری داده‌اید، آن را ذکر کنید.

متن کامل مجوز: <https://creativecommons.org/licenses/by/4.0/legalcode>

## نکته‌ی مهم

این قالب‌ها **مشاوره‌ی حقوقی محسوب نمی‌شوند**. برای استفاده‌ی واقعی، قرارداد را با یک وکیل یا متخصص حقوقی بررسی کنید.
